Gestión de usuarios

Por seguridad, los usuarios ya no se crean desde el navegador (así nadie puede crear cuentas propias leyendo el código de la página). Para crear o eliminar un usuario de portería, hazlo desde el panel de Supabase:

  1. Entra a Authentication → Users en Supabase.
  2. Clic en Add user, marca Auto Confirm User.
  3. Email: usuario@sistema-porteria.local (usa el nombre de usuario que quieras antes de la @).
  4. En User Metadata agrega: {"rol":"admin"} o {"rol":"portero"}.
